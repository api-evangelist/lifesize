# Lifesize

> Lifesize is a video conferencing and meeting-room platform — Lifesize Cloud meeting
> service, Icon conference-room systems, Lifesize Share wireless presentation, Phone HD,
> and web/desktop/mobile apps. Lifesize merged with contact-center provider Serenova
> (CxEngage) in 2020 and was acquired by Enghouse Systems in 2023; the video business now
> operates as Enghouse Video (Vidyo Inc.) and the Lifesize brand continues at
> enghousevideo.com/lifesize. The developer surface is an on-device automation API on the
> Lifesize Icon series — a REST interface plus the Lifesize Automation Command Line
> Interface (CLI) — reached over HTTPS or SSH with administrator credentials.

## APIs

- [Lifesize Icon Automation API](https://support.lifesize.com/product/lifesize-icon-400-450-600-800/advanced-topics/api-overview/): REST plus CLI control interface built into Lifesize Icon systems (models 300–800). Self-documenting on the device at /docs/json (REST) and /docs/clish (CLI). Covers configuration retrieval, preference changes, call status and statistics, and call control.
- [Lifesize Cloud API](https://admin.lifesizecloud.com/): the hosted service API behind Lifesize Cloud, the Admin Console, and the client apps. Base host https://api.lifesizecloud.com is live but undocumented publicly and returns HTTP 403 to unauthenticated callers.

## Specs

- No OpenAPI, Swagger, GraphQL, or AsyncAPI definition is published by Lifesize. The Icon system serves its own JSON reference at https://{videoSystemIPAddress}/docs/json but distributes no machine-readable contract.
